# Data Science Labs

This repository contains coursework, assignments, and practical lab implementations for the Data Science Senior A course. It covers core data science concepts, including environment setup, exploratory data analysis, data cleaning, and data wrangling using Python and Pandas.

---

## Getting Started

### 1. Clone the Repository

```bash
git clone [https://github.com/Wambura001/data_science_labs.git](https://github.com/Wambura001/data_science_labs.git)
cd data_science_labs

```

### 2. Set Up the Environment

Create and activate a virtual environment (optional but recommended):

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

```

Install the required packages:

```bash
pip install pandas numpy jupyterlab

```

### 3. Launch JupyterLab

```bash
jupyter lab

```

2. **Week 2 & 3 – Data Wrangling & Analysis (`pandasDataWrangling.ipynb`, `firstJob.ipynb`)**
